# SNS 캘린더 · kang88

[https://sns.kang88.io](https://sns.kang88.io)

LinkedIn, X, Threads 등의 게시 계획과 초안, 발행 기록을 관리하는 개인 콘텐츠 캘린더입니다. 전화중국어 학습장의 밝은 Material 3 스타일을 바탕으로 새로 만들었습니다.

## 사용 방법

- **캘린더:** 월/주 이동, 채널 필터, 날짜 선택 후 게시물 추가.
- **게시물:** 제목·본문·메모 검색, 진행 상태 필터, 날짜/수정순 정렬.
- **아이디어:** 날짜를 정하기 전 글감 보관. 편집에서 채널과 게시 날짜를 정할 수 있습니다.
- **편집:** 채널, 상태, 날짜·시간, 언어, 본문, 발행 링크, 준비 메모를 저장합니다. 복제하여 다른 채널용 초안을 만들 수 있고, 삭제 직후 실행 취소할 수 있습니다.
- **설정:** 주간 발행 목표, JSON 백업 다운로드·가져오기, 채널 바로가기.

**날짜는 게시 계획입니다.** 이 앱은 SNS에 자동으로 글을 올리거나 예약 발행하지 않습니다. 직접 발행한 뒤 상태를 `발행 완료`로 바꾸고 URL을 저장하세요.

## 기록은 어디에 저장되나요?

새로 입력한 내용은 **이 브라우저의 localStorage**에만 저장됩니다. 로그인이나 서버 전송이 없으며, 다른 기기·브라우저와 자동 동기화되지 않습니다. 브라우저 데이터를 지우기 전이나 기기를 바꾸기 전에 `설정 → 백업 파일 다운로드`를 사용하세요.

백업 가져오기는 파일 전체를 검증한 뒤 병합합니다. 같은 ID는 최근 수정된 기록을 유지하고, 현재 주간 목표는 그대로 둡니다. 손상된 저장 내용은 자동으로 덮어쓰지 않으며 원본 다운로드와 명시적인 복구를 제공합니다. 다른 탭의 변경과 충돌하는 편집은 저장을 차단해 덮어쓰기를 방지합니다.

처음 접속할 때는 2026년 9월 17일 실제 발행한 GIWA 관련 LinkedIn/X 게시물 두 건을 표시합니다. 이 공개 기록만 `seed.js`에 포함되어 있습니다. 원본 중국어 학습 사이트는 수정하지 않았습니다.

## 개발

작업 폴더: `/Volumes/T9/01_Project/SNS`

프레임워크나 런타임 패키지 없이 HTML/CSS/ES modules로 동작합니다. Node.js 24 권장. `file://` 대신 정적 서버에서 실행하세요.

```sh
python3 -m http.server 8891 --bind 127.0.0.1
npm run check
npm test
npm run build
```

`npm run build`는 공개할 7개 파일만 `dist/`에 복사합니다. 문서, 테스트, 내부 검증 기록은 배포되지 않습니다.

| 파일 | 역할 |
| --- | --- |
| `index.html`, `styles.css` | 화면 구조와 반응형 디자인 |
| `app.js` | 캘린더, 편집, 검색, 백업 UI |
| `core.js` | 날짜·게시물 검증, 필터, 통계 |
| `store.js` | 버전별 로컬 저장, 가져오기·내보내기 |
| `seed.js` | 시작용 공개 발행 기록 |
| `DESIGN.md` | 디자인 및 UX 기준 |
| `tests/model.test.js` | 데이터·날짜·저장 회귀 검사 |
