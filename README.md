# SNS 캘린더 · kang88

[https://sns.kang88.io](https://sns.kang88.io)

LinkedIn, X, Threads, YouTube 등의 게시 계획과 원고 보관, 발행 기록을 관리하는 개인 콘텐츠 캘린더입니다. 전화중국어 학습장의 밝은 Material 3 스타일을 바탕으로 새로 만들었습니다.

## 사용 방법

- **캘린더:** 월/주 이동, 채널 필터, 날짜 선택 후 콘텐츠 추가. 월 화면은 날짜별 채널 아이콘만 압축해서 보여주고, 상세 내용은 선택한 날짜 패널에서 확인합니다.
- **보관함:** 발행 완료 전 콘텐츠를 모아 봅니다. 날짜 없는 원고를 저장하고, 준비되면 `일정 잡기`로 캘린더에 올릴 수 있습니다.
- **발행 기록:** 직접 발행한 콘텐츠의 날짜와 원문 URL을 남깁니다.
- **검색:** 상단 검색은 보관 중인 콘텐츠와 발행 기록 전체의 제목·본문·메모·URL을 검색합니다.
- **편집:** 채널, 상태, 날짜·시간, 언어, 본문, 발행 링크, 준비 메모를 저장합니다. 본문 복사, 복제, 삭제 직후 실행 취소를 지원합니다.
- **설정:** 주간 발행 목표, JSON 백업 다운로드·가져오기, 채널 바로가기.

**날짜는 게시 계획입니다.** 이 앱은 SNS에 자동으로 글을 올리거나 예약 발행하지 않습니다. 직접 발행한 뒤 상태를 `발행 완료`로 바꾸고 URL을 저장하세요.

## 기록은 어디에 저장되나요?

새로 입력한 원고와 일정은 **이 브라우저의 localStorage**에 저장되며, 다른 기기·브라우저와 자동 동기화되지 않습니다. 사진 보관함을 연결한 경우 사진만 Supabase로 전송됩니다. 브라우저 데이터를 지우기 전이나 기기를 바꾸기 전에 `설정 → 백업 파일 다운로드`를 사용하세요.

`설정 → 백업 가져오기`에서 이 앱이 내보낸 버전 1 JSON 파일을 선택하세요. 10MB 이하 파일 전체를 검증하고 추가·갱신·유지할 기록 수를 확인한 뒤 병합합니다. 같은 ID는 수정 시각이 더 최신인 기록을 유지하며, 시각이 같으면 현재 기록을 유지합니다. 현재 주간 목표는 바뀌지 않고, 파일에 없는 기존 기록도 삭제하지 않습니다.

손상된 저장 내용은 자동으로 덮어쓰지 않습니다. 설정에서 원본을 먼저 다운로드한 뒤 유효한 백업을 가져와 `백업으로 복구`를 선택하세요. 이 복구는 일반 병합과 달리 백업의 기록과 주간 목표로 저장 내용을 교체합니다.

다른 탭의 변경을 감지하면 열린 편집창의 저장을 차단합니다. 작성 중인 내용을 복사해 두고 편집창을 닫은 뒤 다시 열어 최신 기록에 반영하세요. 저장 직전에도 마지막으로 읽은 저장 내용과 비교하지만, 여러 탭의 동시 쓰기를 잠그는 방식은 아니므로 한 탭에서 편집하는 것을 권장합니다.

처음 접속할 때는 2026년 9월 17일 실제 발행한 GIWA 관련 LinkedIn/X 게시물 두 건을 표시합니다. 이 공개 기록만 `seed.js`에 포함되어 있습니다. 원본 중국어 학습 사이트는 수정하지 않았습니다.

## 사진 보관함 (0.3.0)

현재 운영 버전은 0.3.0입니다. 사진 보관함은 무료 서울 리전 Supabase 프로젝트에 연결되어 있습니다.

Supabase Free의 비공개 저장소를 사용합니다. 연결 후 `설정 → 사진 보관함`에서 허용된 관리자 계정으로 로그인하면 콘텐츠 편집창에 사진을 첨부할 수 있습니다. JPG·PNG·WebP, 장당 6MB, 콘텐츠당 최대 10장입니다. 로그인은 현재 탭에 유지됩니다.

- 사진 선택과 제거는 `저장`을 누르기 전까지 반영되지 않습니다. 취소하면 원래 사진이 유지됩니다.
- 원고 저장 후 사진을 업로드합니다. 업로드가 실패하면 원고는 남고 편집창에서 저장을 다시 눌러 같은 기록에 이어서 올릴 수 있습니다.
- `발행 완료`로 저장하면 원고·날짜·링크는 유지하고 보관한 사진을 삭제합니다. 삭제 실패나 로그아웃 상태에서는 안내가 남으며 로그인·네트워크 복구·사진 정리 버튼으로 다시 시도합니다. SNS에 올린 사진에는 영향을 주지 않습니다.
- 기록을 삭제하면 실행 취소 시간을 위해 사진은 20초 동안 유지됩니다. 취소하지 않으면 연결된 상태에서 사진도 정리합니다. 사진 정리 전에는 브라우저 데이터를 지우지 마세요.
- 복제는 새 원고를 만들며 사진은 별도로 첨부합니다. JSON 백업에는 사진 원본과 삭제 대기 목록이 포함되지 않습니다. 같은 사진 계정으로 로그인하고 원고 백업을 가져오면 같은 ID의 보관 중인 사진을 다시 연결합니다. 이미 삭제된 사진은 복원되지 않습니다.

공개 회원가입은 차단되어 있으며 허용된 관리자 계정만 사진에 접근합니다. 운영 사이트에서 로그인, 업로드·재접속, 발행 후 사진 삭제와 기존 원고 보존을 검증했습니다. [설정 절차와 검증 기준](supabase/README.md)을 참고하세요.

## 개발

현재 작업 폴더: `/mnt/j/01_Project/SNS`

이전 macOS 경로는 `/Volumes/T9/01_Project/SNS`입니다.

프레임워크나 런타임 패키지 없이 HTML/CSS/ES modules로 동작합니다. Node.js 24 권장. 프로젝트 폴더에서 검사를 실행하세요.

```sh
npm run check
npm test
npm run build
```

로컬 미리보기는 `file://` 대신 정적 서버를 사용합니다. `uv`가 설치된 환경에서는 아래 명령을 실행하고 [http://127.0.0.1:8891](http://127.0.0.1:8891)을 여세요. 서버를 종료하려면 터미널에서 Ctrl+C를 누릅니다.

```sh
uv run python -m http.server 8891 --bind 127.0.0.1
```

`npm run build`는 공개할 정적 파일 10개만 `dist/`에 생성합니다. Supabase 공개 설정은 빌드 환경변수에서 읽습니다. 문서, 테스트, 내부 검증 기록은 배포되지 않습니다.
